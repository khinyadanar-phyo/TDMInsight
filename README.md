# TDM Insight – 4-Page Vancomycin TDM App

This updated Android Jetpack Compose prototype uses a four-page workflow:

1. **Home** – introductory hospital-style landing page with “Go to Vancomycin Calculation Method”.
2. **Calculation Method** – choose Pre, Post, or Pre + Post, then press **Next**.
3. **Patient & Sampling Data** – enter patient parameters, medication and sampling information, then press **Calculation Result**.
4. **Calculation Result** – displays calculated values and the calculation explanation. **Go back to the Start** returns to Home and resets the form.

### UI improvements
- Hospital-inspired blue/teal Material 3 palette
- Cards and section grouping for clinical-style data entry
- Icons and step indicators
- Animated page transitions
- Back navigation between workflow pages
- Clear result and explanation presentation
- Responsive scrolling for smaller screens

### Build
Open the project in Android Studio, sync Gradle, and run on an emulator/device.

**Clinical scope:** Academic prototype. Use fictional cases only. Clinical equations and targets must be lecturer-approved before real-world use.
